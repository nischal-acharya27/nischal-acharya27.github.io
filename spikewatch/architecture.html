v0.2.0 in one glance
  • Single asyncio loop on one daemon thread.
  • aiohttp + Semaphore(20) ⇒ ~50s sweep → ~3–5s.
  • One trade_state.step shared live + backtest.
  • Pluggable Strategy registry (3 built-ins, file-per-strategy).
  • SQLite trade history; lifetime view loads on launch.
  • One log-returns Sharpe + Sortino + Calmar (crypto calendar).
  • Header-driven rate limiter; 429 backoff.
  • QSettings persists all inputs + window geometry.
  • Status bar w/ per-exchange sweep telemetry.
  • 89 tests passing; CHANGELOG-gated version bumps.
